# 数三雷达 · Math3 Radar

考研数学三历年真题的**考点考频分析**与**个性化复习优先级排序**工具。

**在线使用**：<https://cloud1-d4gsgj705497df85d-1501559031.tcloudbaseapp.com/math3-radar/>

## 它解决什么问题

考研数学三满分 150 分，19 个考点章节的分值分布并不均匀，而且每年都在变化。市面上的"分值分布"只存在于培训机构的一篇篇静态文章里——看完记不住、没法比较、更没法结合自己的薄弱点。

数三雷达把这些数据做成了**可交互的分析工具**：

1. **考频总览**：章节 × 年份的分值热力图 + 年均分值排行 + 三大学科实际占比 vs 考纲比例，一眼看出哪些章节是"重头戏"。
2. **命题趋势**：三大学科分值堆叠走势、单学科下各章节的历年走势，识别"正在变重/变轻"的章节。
3. **我的优先级**（核心）：对每章自评掌握度（1–5），工具按

   > 优先级 = 章节年均分值 ×（6 − 掌握度）　　建议时间占比 = 该章优先级 ÷ 全部章节优先级之和

   实时算出个性化复习排序。直觉：**分值越重、你越生疏的章节，越该先复习**。
4. **数据说明**：每一年、每一条数据的来源链接，以及口径与局限的完整说明。

## 数据与口径

- 章节体系按考研数学三考纲划分为 18 章（高数 6 章 / 线代 5 章 / 概率统计 7 章）。
- 各年分值数据**不是**取自机构发布的分值分布表（那些几乎全是图片，无法机器核实），而是由一个覆盖 386 道数三真题的逐题考点库聚合而成：每题的官方分值与考点标注映射到 18 章体系，逐年汇总；2025 年卷另用独立来源逐题交叉核对，单卷总分逐卷校验 = 150（14/14 通过）。详见站内「数据说明」页（含 10 个来源链接与 6 条口径说明）。
- **查不到的数据一律记为空值，不猜测、不插补**；年均分值仅按有数据年份计算。
- 掌握度自评仅保存在本机浏览器（localStorage），不上传任何数据。

## 技术实现

- 纯前端单页应用，零依赖构建：原生 HTML/CSS/JS + Apache ECharts（本地打包，离线可用）。
- 数据层：构建脚本（`tools/build_data.py`）把采集核实的 JSON 数据生成为静态 `data.js`。
- 部署：腾讯云 CloudBase 静态托管，独立子域名，手机可直接访问。

## 本地运行

```bash
cd math3-radar/public
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 模型局限（诚实声明）

线性加权是最简单的优先级模型：它没有考虑题目难度、命题趋势的变化速率和个人目标分。
这些是明确的改进方向——例如对"近 3 年分值"给更高权重、引入章节难度系数做加权回归等。
